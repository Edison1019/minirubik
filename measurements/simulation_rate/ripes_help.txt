Ripes command line interface.
The command line interface allows for assembling/compiling/executing a 
program on an arbitrary processor model and subsequent reporting of 
execution telemetry.
Command line mode is enabled when the '--mode cli' argument is provided.

Options:
  --mode <mode>                Ripes mode [gui, cli]
  --src <path>                 Path to source file.
  -t <type>                    Source file type. Options: [c, asm, bin, elf]
  --proc <name>                Processor model. Options: [RV32_SS, RV32_5MC_2M,
                               RV32_5MC_1M, RV32_5S_NO_FW_HZ, RV32_5S_NO_HZ,
                               RV32_5S_NO_FW, RV32_5S, RV32_6S_DUAL, RV64_SS,
                               RV64_5MC, RV64_5MC_1M, RV64_5S_NO_FW_HZ,
                               RV64_5S_NO_HZ, RV64_5S_NO_FW, RV64_5S,
                               RV64_6S_DUAL, RV32_ISS, RV64_ISS]
  --isaexts <extensions>       ISA extensions to enable (comma separated)
  --reginit <regfile:[rid=v]>  Comma-separated list of register initialization
                               values. The register value may be specified in
                               signed, hex, or boolean notation. Can be used
                               multiple times to initialize more than one
                               register file type. Format:
                               <register file>:<register idx>=<value>,<register
                               idx>=<value>
  --timeout <ms>               Simulation timeout in milliseconds. If
                               simulation does not finish within the specified
                               time, it will be aborted.
  -v                           Verbose output
  --output <path>              Report output file. If not set, report is
                               printed to stdout.
  --json                       JSON-formatted report.
  --all                        Enable all report options.
  --cycles                     Report cycles
  --iret                       Report instructions retired
  --cpi                        Report cycles per instruction (CPI)
  --ipc                        Report instructions per cycle (IPC)
  --pipeline                   Report pipeline state
  --regs                       Report register values
  --exectime                   Report wall-clock model execution time (ms)
  --runinfo                    Report simulation information (processor
                               configuration, input file, ...)
  --cache-preset <name>        Enable L1 instruction & data cache simulation
                               using a named preset (as listed in the GUI cache
                               tab). Applies the preset to both caches.
  --cache-config <path>        Enable L1 cache simulation from a JSON spec
                               file. The document may contain "L1I" and/or "L1D"
                               objects; each object requires integer fields
                               "blocks", "lines" and "ways" and optionally
                               "writePolicy" (writeback|writethrough),
                               "writeAllocatePolicy"
                               (writeallocate|nowriteallocate) and
                               "replacementPolicy" (lru|random). A cache is
                               simulated only if its object is present.
  -?, -h, --help               Displays help on commandline options.
  --help-all                   Displays help, including generic Qt options.
